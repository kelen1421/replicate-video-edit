# 包装复刻与工具分工

## 确定要对齐的图层

先选一个同时有人物、文字和运动的代表镜头。标出主体中心、裁切边缘、标题基线、前后遮挡和音效落点。记录哪几层按参考重建、哪几层用新素材、哪几层省略。包装 1:1 依照约定的图层逐项验收。

- **简笔 A-roll。** 将主讲人独立成层。全屏、拱形、圆窗和手机屏内的同一位主讲人都要替换。沿用相应的景别、锚点、缩放曲线和遮罩。把位于主讲人身后的标题和挡在前方的强调词分层，保留原有的进出场关系。
- **B-roll。** 照片、屏幕演示、课程卡和实拍插镜按叙事功能逐段核对。用户允许生成时，可补所缺画面并对齐构图、进出点、运动方向和停留帧数。合影中的人物、截图中的账号界面和软件图标按 B-roll 内容处理。随素材记录哪些来自原始文件、分层提取、重绘或生成。
- **水印。** 分清平台或发布者后叠的角标与课程卡内的原有标识。复刻侧优先使用干净底图，必要时补出被角标遮住的纸纹、网格或边框。抽查角标跨越不同底色、镜头切换和缩放时的边缘。参考侧展示提供的原片。
- **文字和声音。** 分别处理口播转写、卡内正文与包装强调词。纯音效成片使用独立音效轨。只有混音且无法分离干净时，按翻页、滑入、点击、落点等可见动作重新拟音并标注来源。网页监听可以单独选左侧原声，字幕按需挂在右侧，保留纯音效母版。
- **验收。** 在指定保留的图层比较位置、字距、遮挡、缓动和声画落点。对替换过的人物或素材可比较几何与时间。全画面相似度会受到替换面积影响，不能单独证明包装已达到 1:1。

## 《副业赛道》实际使用的软件

| 软件、引擎或程序库 | 在这次制作中的用途 | 可继续修改或核对的内容 |
|---|---|---|
| Kdenlive 26.08.3 | 打开并核对分层时间线，安排 B-roll、画中画、标题和声音对象 | 打开 `.kdenlive` 调整素材、变换关键帧和音效入点 |
| MLT 7.43.0（melt） | 使用 Kdenlive 的渲染引擎输出抽查帧和全片 | 用同一时间线重新导出局部或全片 |
| Glaxnimate 模块 | MLT 读取双路径箭头的动画 JSON | 路径可在 Glaxnimate 中编辑，弹跳位置在剪辑器中调整 |
| FFmpeg / ffprobe 8.1.1 | 视频转码、音轨封装、帧时间戳与音频核对 | 检查分辨率、画面时长、帧数、编码和实际音轨 |
| Python 3.12、OpenCV、NumPy | 生成简笔人物动作，跟踪构图，提取遮罩，重建水印区域；按动作合成包装音效 | 可替换图层、动作关键帧与独立立体声 WAV |
| Pillow | 绘制位图文字和对照标识 | 调整字号、字重与像素位置 |
| 浏览器（HTML5 Video / WebVTT） | 两个独立播放器同步预览，按时间码显示右侧字幕 | 单帧步进、切段、字幕开关、切换监听和叠加核对 |

前期包装稿还用过图像生成工具补画电视机和房间素材，用 macOS Vision OCR 定位、转录原片字幕。简笔人物由路径绘制。软件截图中出现的应用名称属于片中内容。

本例以 1280 × 720、25 fps 制作，19 个场景共 4,127 帧。网页另载入 115 条时间码字幕。后续项目从各自的参考测量分辨率、帧率和字幕条数，在交付说明中列出该项目实际用过的软件及用途。
