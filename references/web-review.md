# 把两版放入网页窗口

用户提出「左右对比」「对比版」「在网页里对着看」时，把原片和复刻片作为两个独立媒体源，生成已经绑定两侧的项目页。在用户正在使用的网页面板打开这份项目页。左、右可保留独立画幅，暂停、切段、逐帧和叠加共用时间线。

## 生成可直接观看的项目

在 Skill 目录下运行，传入浏览器可解码的视频。H.264/AAC MP4 适用于此例。脚本使用 Python 3 和 ffprobe，复制两份媒体到新的输出目录，字幕和段落信息嵌在 HTML 中。

```sh
python3 scripts/make_review.py 原片.mp4 复刻.mp4 网页对照 \
  --title "原片与简笔复刻" --cut-title "简笔复刻" \
  --audio left --captions 口播.srt
```

- `--audio left` 让原片原声单独播放。按用户指定也可选 `right` 或 `none`。两条视频自身的音轨保持独立。
- `--captions` 接收以**右侧成片时间码**编排的 UTF-8 SRT。等长同剪点时可直接复用原片 SRT；改过剪辑时先按段落映射调整。原片内嵌字幕随原片显示。如果成片已经烧录同样的文字，省略这一项。用户可用「同步字幕」单独开关右侧字幕。
- 时长与剪点一致时，默认可整片连看。分段、移位或使用不同片段时，传 `--segments 分段.json`。JSON 为按成片顺序排列的数组。每项形如 `{"title":"片头","a0":3.2,"a1":5.2,"b0":0,"b1":2}`。A 对应原片，B 对应成片，单位为秒，出点不包含在内。逐帧核对前宜用统一的恒定帧率。
- 需要多条参考时，仍可在对照台添加参考，逐段绑定参考和时间范围，导出项目记录。额外关联的本地视频随包携带。

## 打开并点验

1. 打开输出目录里的 **左右对照.html**。如果应用内浏览器要求 HTTP，用仅绑定本机的静态服务器提供该目录，选支持 HTTP Range 的服务器以便视频跳转。已有对照台窗口时，直接展示带两条媒体的项目页。
2. 确认两侧首帧和名称都已加载，选中用户指定的声音侧，另一侧静音。播放后暂停，单步前进一帧；在一条字幕入点和出点两侧各检查一帧。再跳到中段和末段，核对声音、画面和字幕仍对齐。
3. 给用户可打开的网页入口。需要在其他机器看时，将 HTML 和同层「视频」目录一并打包，使用相对路径。Skill 包只携带通用模板与生成脚本，具体项目的两条视频随项目交付。
