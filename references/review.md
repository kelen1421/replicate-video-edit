# 视频拆解和验收

## 项目与分段

- 参考来源、版本、画幅、帧率、时间零点、有效正片裁框。
- 每行一个可以独立复刻的段落。填写成片 IN/OUT、参考视频、参考 IN/OUT、主任务、状态。
- 同一段落若同时使用多个参考，用备注记录「参考 A 看构图，参考 B 看动画」，附各自区间。主参考用于同步；其余可随时切换。
- 平台来源页和用于逐帧的本地媒体分别记录。若使用剪过的参考副本，标清原始时点和副本偏移。
- 如有录屏、变速或可变帧率，先对齐有效第一帧并确定输出时基。用逐帧解码检查真实切点。
- 原素材映射记录：素材标识、素材 IN/OUT、成片 IN/OUT、选用理由；锁定的镜头或版本按用户名称保留。

## 逐镜对照表

| 检查单位 | 记录 | 验收 |
|---|---|---|
| 切点 | 成片帧号、参考帧号、剪点类型、前后各一帧 | 同时对照出镜和入镜，核对是否有闪帧或出入点偏移 |
| 机位和构图 | 拍摄视角、景别、主体中心及关键点、透视、地平线，统一用有效画面比例标注位置 | 用三分线和叠加比对。取首、中、尾帧，手工确认关键点落在对应位置 |
| 运镜 | 关键帧、画面缩放、旋转、位移、轨迹、缓动、遮挡和定格 | 同帧叠加比静态落点，原速比较开始、过程和收住的节奏 |
| 图形和文字 | 图层、图形方向、文字内容、字重、颜色、行宽、锚点、入出场、遮罩、速度曲线 | 以有效画幅核对边距和标题落点，逐帧查看动效从哪一帧开始与结束 |
| 声音 | 开口、停顿、换人、重拍、配乐和音效电平、是否夹杂背景声音 | 切换监听两侧。对白单听再带配乐听，核对口型与原速节奏 |
| 画面来源 | 前后状态、真正同帧与拼接、拍摄光线或机位差异 | 只将核实过的拍摄状态用于对照，给素材来源保留链路 |

## 读入 rea-video 的拆解结果

- [rea-video 公开技能](https://github.com/JuneYaooo/rea-video/blob/main/skills/rea-video/SKILL.md)按镜头分层记录。先从索引定位镜头时间轴，按需打开单镜头证据、节奏、声音和包装。用关键帧联系图判断段落，疑似跳切、遮挡转场或暗底合并另外抽相邻帧核实。
- 参考源的测量、镜头制法的推断，以及成片的还原参数分别留列。有生成、拍摄和代码渲染混合时，给每层定执行路径。对实拍加文字和箭头的项目，先对齐实拍再重建文字和箭头。
- 将确认过的参考入出点、成片入出点和关键切点写入对照台。将复现偏差回填到镜头位置和动画效果。报告的候选切点与分层描述需要对照原片复核后才能用于 1:1 验收。

## 导出工程的微调验收

从粗剪开始给每个可调对象命名，保留时间线帧号、源素材与所属对象。选择同时出现多个元素的一段，在导出工程的副本上检查。

| 对象 | 在剪辑器里的操作 | 回看结果 |
|---|---|---|
| 主画面和画中画 | 关闭画中画，再单独移动或裁切它。上下对照分别替换其中一张 | 底图保持完整，另一张的位置和裁切保持原值 |
| 字幕 | 改一个字，把这句入点向后移一帧 | 新文字和新入点生效，相邻字幕和图形照常出现 |
| 图形和动画 | 单独选箭头或标注，移动一个中间关键帧，检查起点、终点与缓动 | 只有目标元素的运动改变。字幕和镜头运动仍用各自的关键帧 |
| 转场和声音（镜头含有时） | 调整转场一帧，或单听对白、配乐、音效 | 两侧原素材能覆盖新的过渡区间，各声音对象可分别调节 |

保存、关闭，再打开修改后的工程，抽查修改点及其相邻帧并短导出。遇到格式转换，逐项记录实际保留的文字、遮罩和关键帧。附带的 ASS、SRT 或动画预览可以补充工程；单靠这些文件不能证明时间线上有可编辑对象。

## 允许差异和交付

- 把首末帧、关键位置、运动中间帧逐项对照，不用观感同义词替代可测参数。偏差写成帧差或有效画幅坐标差，并给出复查位置。
- 镜头中心相同但透视不同、文字结束状态相同但缓动不同，均标成待调整。1:1 目标无法满足时保留可验证的差异。
- 同一个项目可以切换留档版和当前成片。版本时间线不同，另外保存该版本的分段映射。
- 项目记录可导出 JSON。记录包含选择、时间码和验收备注。跨设备打开需要关联对应视频文件。
